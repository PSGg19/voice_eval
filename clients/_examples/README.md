# `clients/_examples/`

Reference scenarios for the V2 AI-driven caller. These three files
demonstrate the full schema and the three barge modes.

| File | What it tests |
|---|---|
| [happy-path.yaml](happy-path.yaml) | Turn-taking mode (no barge). Demonstrates F12 conversational realism (filler words, self-corrections). |
| [barge-scheduled.yaml](barge-scheduled.yaml) | Scheduled barge mode — engine fires interruptions at specific turn numbers. |
| [barge-llm.yaml](barge-llm.yaml) | LLM-mode barge — caller LLM decides when to interrupt, using the BCD for bot-specific context. |

## How to use these

**Don't edit in place.** Copy into your client's directory and customize:

```bash
mkdir -p clients/acme/scenarios
cp clients/_examples/happy-path.yaml clients/acme/scenarios/payment-flow.yaml
# Now edit clients/acme/scenarios/payment-flow.yaml for the Acme bot.
```

Then run:

```bash
opkura lint "clients/acme/scenarios/*.yaml"
opkura run clients/acme/scenarios/payment-flow.yaml
```

The `_examples/` prefix sorts them above any real client directory and
signals they're not a real client suite.

## BCD prerequisite for `barge-llm.yaml`

`barge-llm.yaml` references `clients/resurgent/bargin-context.md` via
`barge_in.bot_context_path`. That file is generated by:

```bash
opkura bcg <bot-system-prompt-path> -o clients/resurgent/bargin-context.md
```

Without it, `opkura lint clients/_examples/barge-llm.yaml` exits 1 with
`missing_bcd` — documented expected behavior.
